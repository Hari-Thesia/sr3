# The Lake Side — Confidential Dossier landing page

Next.js 14 (app router) + Tailwind CSS + lucide-react.

    npm install
    npm run dev      # http://localhost:3000

Before launch:
- Replace public/dossier/The-Lake-Side-Confidential-Dossier.pdf with the real dossier.
- Wire the TODO in app/page.jsx (submit) to your CRM / WhatsApp Business API.
- Fill in the RERA number and legal text in the footer.
